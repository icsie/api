# FastAPI Test API

A small FastAPI project for testing a Python API service. The current implementation provides health and version endpoints and a simple item creation endpoint.

## Features

- Health check endpoint
- API version endpoint
- Pydantic validation for item data
- Interactive API documentation generated by FastAPI

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn

## Requirements

- Python 3.10 or newer

## Installation

Create and activate a virtual environment:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

Install the project dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run Locally

Start the development server from the project root:

```powershell
uvicorn app.main:app --reload
```

The API is available at:

- http://127.0.0.1:8000
- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## API Endpoints

### `GET /health`

Returns the service health status.

```json
{
  "status": "ok"
}
```

### `GET /version`

Returns the current API version.

```json
{
  "version": "0.1.0"
}
```

### `POST /items`

Accepts an item and returns the validated request data.

Request body:

```json
{
  "name": "Notebook",
  "price": 12.5
}
```

Response body:

```json
{
  "name": "Notebook",
  "price": 12.5
}
```

## Database Status

PostgreSQL integration is not implemented yet. The current `/items` endpoint validates and returns the request data without storing it in a database.
